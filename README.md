# World Wide Web · rediseño del primer sitio web del CERN

Proyecto educativo del **COVAO** (Colegio Vocacional de Artes y Oficios, Costa Rica), hecho por Yeiner Vindas Hernández.
**No es un sitio oficial del CERN.** Es un tributo al primer sitio web del mundo, publicado por el CERN en [info.cern.ch](http://info.cern.ch/).

🌐 Sitio: https://w3.covao.dev/

## Qué es
Un rediseño interactivo del proyecto WorldWideWeb (W3) y de su documento central, con escenas 3D (Three.js / WebGL), una red de enlaces tocable, buscador interno y cinco idiomas (ES, EN, PT, FR, DE).

## Contenido original
Los textos provienen de la página original: <http://info.cern.ch/hypertext/WWW/TheProject.html>.

## Tecnología
HTML, CSS y JavaScript en un solo archivo. Three.js r128 desde cdnjs. Sin dependencias de compilación.

## Publicar
Sube `index.html`, `robots.txt`, `sitemap.xml` y `og-image.png` a la raíz del sitio (GitHub Pages, Netlify o Vercel).
